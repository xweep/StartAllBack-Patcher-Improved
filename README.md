# StartAllBack Patcher – v1.0.0

Improved version of the original StartAllBack patcher, mainly made to fix administrator errors on debloated Windows ISOs and issues with the latest update.

## What's Improved

- Fixed administrator permission errors.
- Fixed DLL replacement issues.
- Added automatic backups and rollback.
- Added checks for existing patches and outdated backups.
- Added SHA-256 verification.
- Improved error handling and Explorer restarting.

## How to Use

1. Download the `.bat` file from the [latest release](https://github.com/xweep/StartAllBack-Patcher-Improved/releases/latest).
2. Right-click and run as administrator.
3. Wait for the script to finish.

**Tested for StartAllBack 3.9.28.**
